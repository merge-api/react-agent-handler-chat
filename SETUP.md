# Setup Guide

## Initial Setup

### 1. Install Dependencies

```bash
npm install
```

### 2. Build the Package

```bash
npm run build
```

This creates the `dist/` directory with:
- `dist/index.esm.js` - ES Module build
- `dist/index.umd.js` - UMD build  
- `dist/index.d.ts` - TypeScript definitions

### 3. Test Locally

Use `npm link` to test before publishing:

```bash
# In this directory
npm link

# In your test project
npm link @mergeapi/react-agent-handler-chat
```

## Publishing to npm

### 1. Login to npm

```bash
npm login
```

### 2. Publish

```bash
npm publish --access public
```

### 3. Verify

```bash
npm view @mergeapi/react-agent-handler-chat
```

## Version Management

```bash
# Patch (1.0.0 -> 1.0.1)
npm version patch

# Minor (1.0.0 -> 1.1.0)  
npm version minor

# Major (1.0.0 -> 2.0.0)
npm version major

# Then publish
npm publish
```

## Prerequisites

Before this package works, ensure:

1. **agent-handler-chat widget is deployed** to CDN:
   - Production: `https://ah-cdn.merge.dev/chat.js`
   - Development: `https://ah-cdn-develop.merge.dev/chat.js`
   - Local: `http://localhost:3007/chat.js`

2. **Widget exposes** `window.AgentHandlerChat` API:
   - `initialize(config)` 
   - `open(config?)`
   - `close()`
